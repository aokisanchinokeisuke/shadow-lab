# Shadow Lab — 光と影の実験室

研究用の設置空間シミュレータ。既存のgen04トリケラトプスを読み込み、移動光源による壁面の影と、近づくと現れる影内の骨格を比較するローカルWebアプリです。

## 起動

Node.js 22.12以上（検証環境は24.16）を使用します。

```sh
cd /Users/aokikeisuke/Research_master/shadow-lab
npm install
npm run dev
```

表示された `http://127.0.0.1:5173` をWebGL2対応ブラウザで開きます。`file://` で直接開かないでください。外部API、APIキー、外部フォントは不要です。インストール後の動作はローカルで完結します。

## 操作

- 光源に付いた軸矢印：ライトをドラッグ。
- 背景ドラッグ／スクロール：空間視点の回転／拡大縮小。
- 矢印キー：左右、前後。Q／E：下／上。入力欄にフォーカスがある間はライトを動かしません。
- 15／30／45 cm：ライトを模型中心と同じ高さ・横位置へ戻し、距離を設定。
- 「近づくと骨格を表示」：骨格投影のON/OFF。初期設定では45 cmは影のみ、30 cmはフェード途中、15 cmは骨格が明瞭に表示されます。骨格の出現距離・フェード幅・明るさは右パネル「骨格」で調整できます。
- 前後スライダー：Z方向だけを変更。左右・上下へ動かした場合、表示される直線距離と一致しません。
- 「頭に寄る」「胴体に寄る」：実メッシュの手前側表面を狙い、表面から50 mmの位置へ移動。空間ビューの模型をダブルクリックして任意の部位も選べます。
- 「表面からの前後距離」：現在のライトのX・Yを保ち、手前側表面から0〜100 mmを指定。0 mm指定は数値安定性のため **0.1 mm** の隙間を残し、実際の値を表示します。近接する途中で壁面ビューに切り替えると影の拡大・はみ出しを観察できます。
- 前後Zの最低値は0 m。模型がその位置にある場合は表面の手前で止まり、内部には入りません。模型中心まで0 cmにする機能ではありません。
- 「表面までの最短距離」は全三角形への最短距離で、前後方向の隙間とは区別しています。模型がライトの真後ろにない場合、表面スライダーは無効になります。
- 壁面：影を正面から観察。空間：模型・壁・光源の配置を観察。
- 右パネル：模型‐壁間距離、壁幅、ライトXYZ、照射の半角、影フィルター半径、光源視点FOV、ガイド表示。
- 設定を保存：単位・座標・設定値・距離・近似倍率をJSONとしてダウンロード。

## 座標・素材

単位はメートル。世界座標はX=壁の横方向、Y=鉛直上、Z=壁から体験者側。模型の前後中心はZ=0、台の天面はY=0.72。壁はZ=-ModelWall、ライトはZ>0です。

大きな距離表示は肉付きモデルのバウンディングボックス中心基準です。表面距離は別に表示します。ModelWallも模型中心面Z=0から壁までの距離です。部位への接近と侵入防止は壁に垂直な-Z方向に沿います。模型の背面へ回り込む操作ではありません。

`public/models/body_td.glb` と `skeleton_td.glb` は既存書き出しのコピーです。原版は変更しません。肉付き模型は空間に表示し、骨格は壁への投影画像として表示します。骨格の読込失敗時も肉付き模型と影の操作は継続でき、画面に再試行ボタンが出ます。

GLBの上方向は+Y、長軸はZ。長軸約99.994 mm、高さ約52.456 mm、厚さ約29.435 mmを検査した上で、Y軸に-90°回転し長軸を壁と平行にします。Blenderでの頭=-YはglTFでは+Zとなるため、画面の基準では頭が-Xになります。個別に骨格を再センタリングしないこと（ペアの登録座標を維持）。

## 光学と表示の範囲

標準SpotLight／PCFシャドウマップ（2048²）の光学ベースラインです。ライトは選択部位（初期値は模型中心）を向きます。照射角は半角、FOVは光源視点の小窓専用であり影倍率には影響しません。点光源の強度2.56 cd、距離減衰指数2。ぼかし初期値0。接触付近で影が欠けないようシャドウカメラのnearを実メッシュへの最短距離に追従させ、影の法線バイアスを0にしています。

```text
d_true = |light - modelCenter|
d_axial = light.z
M = (d_axial + ModelWall) / d_axial
近似影幅 = 模型全長 × M
```

近似倍率は模型を中心平面上の薄い物体とみなした値です。厚さを持つ模型の輪郭幅とはわずかに異なります。「頂点射影の幅」は全メッシュ頂点から光源を通る直線と壁平面との交点の外接幅で、実メッシュの幾何的な影の広がりです。壁によるクリップ、スポットライトの照射範囲による欠け、ぼかしは含みません。

近接時の違いは「わずか」ではありません。各点Pの射影は `L + t(P-L)`、`t=(-ModelWall-L.z)/(P.z-L.z)` で決まります。頭への接近は模型や壁画像を拡大する処理ではなく、実際の光源移動です。奥行きが同じ点同士には同じ倍率が掛かるため、「頭だけが必ずきれいに拡大される」とは限りません。手前側の部位の肥大化、輪郭の歪み、影の移動、壁からのはみ出しが生じます。接触に近づくと影が壁を覆い尽くすこともあります。

ライトが模型の奥行き範囲に入ると、連続した模型の射影は無限遠へ発散し得るため、有限な頂点だけの外接幅を影全体の幅とはせず「非有界」と表示します。Z=0では中心面の近似倍率・近似影幅は未定義として「—」にします。壁面上での影は引き続き描画されます。

ModelWall=0.5 mの正対プリセットでは、15 cm→4.333倍、30 cm→2.667倍、45 cm→2.111倍になります。

影のぼかしはシャドウマップのフィルタ半径です。有限発光面による半影の物理シミュレーションではありません。幾何学的な点光源と逆二乗減衰を採用していますが、補助環境光・固定露出・有限解像度の影マップがあり、実測校正はしていません。LEDの発光面が無視できない至近距離では、現物の半影はこの理想点光源と異なります。実機の照度・プロジェクターの黒レベル・実装置遅延の予測には使えません。画面のライト模型は位置ガイドで、近接時は見やすく縮小します。実際のライト筐体の衝突は再現しません。

設計参考：[Three.js SpotLight](https://threejs.org/docs/pages/SpotLight.html)、[LightShadow](https://threejs.org/docs/pages/LightShadow.html)、[PBRT Point Lights](https://www.pbr-book.org/3ed-2018/Light_Sources/Point_Lights)。

台は模型の輪郭を検査しやすいよう影を落としません。ライト小窓には肉付きモデルだけを表示します。三角形数はモデル単体80,000、フッターは複数ビュー等を含むレンダラーの描画カウンターです。FPSは実行環境依存です。

## 骨格の投影と位置合わせ

- 肉付き・骨格とも同一の登録座標、Y回転-90°、高さ0.72 mを使用。骨格単独で中心を取り直したり、肉付きの外接箱へ無理に拡大したりしません。
- 骨格は肉付き模型とは別シーンで、**既存ライトの `light.shadow.camera` そのもの**から2048²のRender Targetへ描画します。これにより肉の遮蔽に隠されず骨格を描画しつつ、骨格同士の前後関係は保ちます。
- 壁面の各点に `light.shadow.matrix` を適用して骨格画像をサンプリングします。通常の壁UVに画像を貼るのではなく、ライトの移動・向き・壁距離に追従する透視投影です。影と骨格の行列は参照も共有します。
- 表示範囲は、実際に影を描いた `light.shadow.map.texture` の深度比較から求めます。Three.js r180と同じ17点PCFサンプルと照射コーンでマスクし、影の外へ骨格が漏れるのを抑えます。
- 壁用の骨格面は壁と同位置で、奥行き差による投影ズレを避けています。描画上の競合のみpolygon offsetで解消します。
- 骨格画像は光源などの設定変更時に再描画し、フェードと観察カメラの移動だけでは再描画しません。影が移動したのに骨格だけ古いまま残ることがないよう、変更時にキャッシュを無効化します。

距離の判定は **模型中心までの直線距離** です。初期出現距離0.34 m、フェード幅0.10 m（0.24 m以下で表示率100%）、境界ヒステリシス±0.015 m、時間平滑化0.16秒。遠方からの接近時は0.325 m以下で状態が切り替わり、後退時は0.355 m以上で遠距離状態へ戻ります。透明度自体は滑らかに変化します。ON/OFFのOFFは即座に消します。

近接時は、肉の外表面と内部の骨の奥行き差による倍率差が自然に残ります。「同じ投影」とは輪郭同士を強制一致させることではありません。頭に寄るとその光源位置から見た頭蓋も投影されますが、接触付近では影が壁を覆う・骨格が部分的に壁外へ出ることがあります。

骨格は展示用の人工的な合成表現であり、通常の光が肉を透過して骨を映す物理現象ではありません。実機プロジェクターの位置補正・画角・明るさ・遅延はまだ再現していません。登録座標の一致と骨格を影内に収めるマスクは実装していますが、生成されたGLB自体の解剖学的な正確さを保証するものではありません。

## 検証

```sh
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

Vitestは倍率、斜め光源での距離分離、射影点、接触防止、実GLBの表面距離に加え、骨格出現のフェード・ヒステリシス、斜め／近接光源での骨格点と壁上交点の投影UV一致、実骨格の変換維持・行列共有を検査します。骨格追加時は計算テスト19件とビルドを検証済みです。GPUでの画素単位の一致や実機校正の検証ではありません。

既存のPlaywrightテストは実GLB読み込み、三距離プリセット、キーボード操作、壁面切替、範囲警告、リセット、JSON保存、スマートフォン幅を検査します。スクリーンショットは `test-results/` に出力します。骨格追加後のブラウザ視覚検証はまだ実施していません。

テストのソフトウェアGPU設定は再現性のためです。そこで表示されるFPSは実機GPUの性能測定値ではありません。

## AI・自動検査用API

```js
window.__SHADOW_LAB__.getState()
window.__SHADOW_LAB__.setPreset(0.15)
window.__SHADOW_LAB__.setParameters({modelWall: 0.7, lightX: 0.05})
window.__SHADOW_LAB__.setView('wall')
window.__SHADOW_LAB__.focusPart('head')
window.__SHADOW_LAB__.approachSurface(0.01) // 10 mm、単位m
window.__SHADOW_LAB__.setParameters({skeleton:true, revealDistance:.34, fadeWidth:.10})
window.__SHADOW_LAB__.reset()
```

`getState()`はloaded、params、dTrue、dAxial、magnification、approximateWidth、projected、modelDimensions、surfaceDistance、surfaceGap、focus、collisionLimited、shadowNear、fps、skeleton等を返します。skeletonはloaded/error/opacity/target/active/dimensions/projectionMatrixを含みます。`setParameters`は許容範囲へ制限し、不正値を無視します。接触付近ではモデル侵入を防ぐため要求したZ座標から補正される場合があります。JSON保存のschemaVersionは3で、骨格の設定・素材・距離基準を含みます。
